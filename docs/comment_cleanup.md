# Documentation and executable change scope

The PHASE5 files remain untouched. PHASE6 is a separate candidate. Earlier comment
cleanup counts are historical, not a claim that this integration is comment-only.

Scientific functions from the canonical thesis implementation are retained. The
new source transformations are explicit and fingerprinted; upstream code is read
locally rather than embedded in public replacement payloads. Prompt functions are
derived from supplied source. Canonical graph/timestamp fixes are applied directly.
An independent TTE attention view replaces the copied private tokenizer body.
Useful explanations of masking, semantic zero rows, train-only normalization,
strict checkpoint selection, integer precision and metric units remain.

Sixteen source/AST checks, 120 path/time bindings and selected synthetic tests
support the canonical controlled/static-none profile. This is not whole-file
identity for every generated module or proof of real-weight numerical identity.
The optional historical oracle is comparison-only and not an integration provider.
Generated original preimages remain in local backups; no upstream legal notice is
intentionally removed or replaced with a thesis license.
